# CHROMA / 色彩实验室

离线配色工具：根据一个基准色生成配色，或自行指定 2–6 种颜色，查看设计预览、收藏和导出。

[在线使用](https://utovia2237.github.io/chroma-studio/)，也可下载并双击打开 `色彩实验室.html`。单文件版可以单独复制到其他文件夹，无需安装或启动服务器。建议使用近期版本的 Edge、Chrome、Firefox 或 Safari。

## 选择颜色

左侧选色面板支持五种方式：

- **色轮**：拖动外圈选择色相，拖动中心方块调整饱和度和明度。聚焦色轮后，方向键每次调整 1°，按住 Shift 则调整 10°。
- **RGB**：输入或拖动 R、G、B 通道，范围为 0–255。
- **CMYK**：输入或拖动 C、M、Y、K 通道，范围为 0–100%。这是无 ICC 配置的屏幕近似换算，不能代替印刷分色。
- **HSB**：调整色相、饱和度和明度；HSB 与 HSV 含义相同。
- **HEX**：输入三位或六位色码，例如 `#ABC`、`#AABBCC`。

HEX 输入框旁的色块可打开系统选色器。左侧「发现色彩的关系」提供邻近、互补、三角和明暗关联色：在探索配色中，点击后设为基准色；在自主配色中，点击后应用到当前选中的颜色栏位。

## 探索配色

1. 选择基准色，再选择双色、三色、四色、五色或六色系列。
2. 选择色彩关系：自然推荐、邻近色、互补色、分裂互补、三等分、四等分或单色系。
3. 选择配色气质：和谐、冲击、低饱和、高饱和、暗调、亮调、暖调或冷调。

打开「保留基准色」时，每组都包含准确的基准 HEX，气质只影响其他颜色。关闭后，基准色也可能随气质调整。暖调和冷调影响生成颜色的色相，锁定的基准色保持不变。

「换一组」生成新的 12 组配色；「再发现 12 组」保留当前结果并追加。每批会打乱色彩关系和明暗模板，避免与上一批相同位置重复；明确指定的色彩关系保持固定。

## 自主配色

「自主配色」位于「探索配色」和「我的收藏」之间。第一次使用时，颜色选项卡沿用探索页当前第一组配色；之后保留自己编辑的颜色。

1. 选择颜色数量，显示 2–6 张颜色选项卡。
2. 点击要编辑的选项卡，再用左侧五种选色方式修改颜色。选项卡和预览即时更新。
3. 需要调整顺序时，把一张选项卡拖到另一张上，两者交换位置，其余颜色不动。鼠标和触屏均可操作；也可聚焦选项卡后按 **Alt + ← / →** 与相邻颜色交换。拖到空白处或按 **Esc** 取消。

排序后，正在编辑的颜色随位置移动，已有预览中的对应两色同步交换。减少颜色数量时，保留排在前面的颜色。例如，把想保留的两色放到前两位，再切换为双色即可。

减少数量不会清除隐藏栏位的色值。再次增加数量时会恢复这些颜色；当前数量、已编辑颜色和顺序也会在刷新后保留。预览、收藏和导出只包含当前启用的颜色。

自主配色不使用配色气质或生成用的色彩关系设置。「换一组」和追加只随机排列指定颜色，不调整其 HEX。颜色较少时，部分排列会重复出现。

## 预览与详情

两种配色模式都支持五种预览：**灵感**混排、**色卡**、**排版**、**渐变**和**界面**。

- 点击卡片底部的小色块复制 HEX；点击大预览或右下角箭头打开详情。
- 详情显示 HEX、RGB、HSL 和近似 CMYK，可复制整组色值、收藏、导出单组 SVG，或将某色应用到选色面板。
- 详情中的对比度检查可选择文字色和背景色，按 WCAG 2.2 显示比值：普通文字 AA ≥ 4.5:1、AAA ≥ 7:1，大字 AA ≥ 3:1。

探索配色的排版预览选择对比最强的两色。自主配色按当前排列显示，便于交换文字色和背景色；请在详情中检查实际使用的两色。渐变包含插值色，导出的色卡保留配色原始色值。

## 收藏、导出与快捷键

点击卡片上的爱心保存配色，在「我的收藏」查看；再次点击可取消。收藏保留保存时的颜色和顺序，后续编辑不会修改已保存的配色。

工具栏「导出」可导出当前页全部配色，包括收藏页；详情中可导出单组 SVG。支持 **CSS 变量、JSON、SVG 色卡**，色值均为实际显示的 sRGB，卡片、详情和导出按序号标识配色。

在探索或自主配色页的空白处按 **Space** 换一组；输入框、按钮、色轮或弹窗有焦点时不触发。按 **Esc** 关闭弹窗，或取消正在进行的拖动。

右上角可切换明暗主题。界面适配桌面和手机，并遵循系统的减少动态效果设置。

## 本地保存与隐私

收藏、选项和自主配色保存在当前浏览器的 `localStorage` 中，键名为 `chroma-studio-v1`。颜色计算和导出在本地完成，工具不会上传这些数据到服务器或 GitHub，其他使用者看不到你的收藏。

不同设备、浏览器、浏览器用户配置、在线地址和本地文件地址，可能使用不同的存储。清理网站数据、使用无痕窗口或浏览器移除存储，都可能导致记录丢失。需要留存的配色请先导出；更换设备时可查看导出的文件，工具目前不提供导入功能。

浏览器不允许存储时，仍可编辑、预览和导出，收藏只在当前页面会话中保留。剪贴板不可用时，可按提示手动复制色值，或下载导出文件。

## 色彩计算

选色使用 sRGB / HSV。探索配色在 OKLCH 中调整明度、色度和色相，超出 sRGB 色域时降低色度，再转换为屏幕显示的 RGB。色相关系不等同于传统颜料色轮。

CMYK 未使用纸张、油墨或 ICC 配置，同一个 RGB 也可对应不同的 CMYK 黑版组合。印刷前请按目标配置转换并打样。

## 开发与验证

运行时无第三方依赖，使用原生 HTML、CSS 和经典 JavaScript 脚本，支持 `file://` 打开。

| 文件 | 用途 |
| --- | --- |
| `index.html` | 开发入口、页面结构与操作说明 |
| `styles.css` | 样式、主题与响应式布局 |
| `color-engine.js` | 色彩换算、配色生成与对比度计算 |
| `app.js` | 交互、收藏、本地保存与导出 |
| `build.ps1` | 生成单文件版 |
| `色彩实验室.html` | 可独立使用的单文件版，请勿直接编辑 |
| `verify.cjs` | 无依赖的颜色算法检查 |
| `verify-browser.cjs` | 使用 Playwright 和本机 Edge 的浏览器检查 |

修改源文件后，在项目目录运行：

```powershell
powershell -ExecutionPolicy Bypass -File .\build.ps1
node --check .\color-engine.js
node --check .\app.js
node .\verify.cjs
```

浏览器检查需要测试环境中已有 Playwright 和 Microsoft Edge。确保 Node 能解析 `playwright` 包后，运行 `node .\verify-browser.cjs`。脚本检查单文件版的颜色记忆、拖动交换、键盘操作、触屏模拟、关联色、收藏、详情、导出和手机布局。截图及测试导出文件写入被 Git 忽略的 `verification/`，检查后可删除。

`index.html` 需要与三个 CSS / JavaScript 源文件放在同一目录；单文件版不需要这些文件。
