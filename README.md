# CHROMA / 色彩实验室

一个可离线使用的配色工作台，采用冷灰界面与设计场景预览。

在线使用：[打开色彩实验室](https://utovia2237.github.io/chroma-studio/)。离线时也可双击 **`色彩实验室.html`** 或打开 **`index.html`**。工具无需后端、API 密钥或依赖安装。

本项目由作者与 OpenAI Codex 协作完成。作者负责产品方向、视觉目标与功能取舍；Codex 协助完成界面、色彩算法、离线构建、测试验证与 GitHub Pages 发布。

## 打开

双击 **`色彩实验室.html`** 即可使用，可以把这个文件单独复制到其他位置。不需要安装依赖、联网或启动服务器。建议使用近期版本的 Microsoft Edge、Chrome、Firefox 或 Safari。

`index.html` 是相同功能的开发入口，需要与 `styles.css`、`color-engine.js`、`app.js` 放在同一文件夹。

## 功能

- **四种选色方式**：360° 色轮与饱和度/明度平面、RGB 通道、CMYK 通道、HSB（也称 HSV）。支持 HEX 三位/六位输入与系统选色器。需求中的 “HGB” 按常见 RGB 模式实现。
- **关联色**：邻近、互补、三角与明暗系列。点击关联色即可作为新的基准色。
- **配色推荐**：双色、三色、四色、五色、六色系列；和谐、冲击、低饱和、高饱和、暗调、亮调、暖调、冷调。还可指定邻近色、互补色、分裂互补、三等分、四等分、单色系。每次生成 12 组，可继续加载。
- **重新发现**：「换一组」重新生成 12 组；「再发现 12 组」保留现有结果并追加。每批都会重新随机分配色彩关系和明暗模板，避免与上一批相同位置重复；指定一种色彩关系时，保持该关系并打乱明暗模板。卡片以序号标识，不使用配色名称。
- **基准色锁定**：默认保留准确的基准色值；风格只调整其余颜色。关闭后，整组颜色可随风格调整。
- **设计预览**：灵感混排、色卡、排版、渐变和界面。抽象海报与界面图形由本地 HTML/CSS 绘制，引用实际配色。排版选择该组中对比最强的一对颜色。
- **配色详情**：查看 HEX / RGB / HSL / CMYK，复制颜色或整组配色、设为基准色、收藏、导出单组 SVG。
- **可读性检查**：可选择任意两色，实时查看 WCAG 2.2 对比度、普通字 AA/AAA 与大字 AA。预览为示意，最终设计请检查实际使用的前景色与背景色。
- **收藏与导出**：收藏、主题和常用选项保存在当前浏览器。可将当前结果或全部收藏导出为 CSS 自定义属性、JSON 数据与可编辑 SVG 色卡。
- **明暗主题与响应式布局**：适配桌面、平板和手机；遵循系统初始主题，支持手动切换。提供键盘焦点、语义标签和减少动态效果支持。

## 操作提示

- 拖动色轮选色相，拖动中间方块改变饱和度与明度。聚焦色轮后用方向键微调，按住 Shift 每次调整 10°。HSB 模式也可用键盘编辑全部通道。
- 点击卡片底部的小色块复制 HEX；点击大预览或右下角箭头打开详情。
- 在页面空白处按 **Space** 换一组；输入框、按钮或弹窗有焦点时不触发。按 **Esc** 关闭弹窗。
- 「我的收藏」按保存时的完整配色显示；数量与风格设置作用于「探索配色」。
- 浏览器禁止本地存储时，仍可使用和导出，刷新后的收藏将无法保留。不同浏览器、浏览器配置或不同本地文件地址可能有各自的收藏。清理浏览器数据前请先导出。

## 色彩原理与边界

基准选色使用 sRGB / HSV。推荐使用 OKLCH 的感知明度、色度和色相关系，结合明暗节奏、低色度中性色与重点色。超出 sRGB 色域时逐步降低色度，避免简单裁切导致明显偏色。邻近/互补等关系围绕感知色相构建；不会与传统颜料色轮完全相同。

这是一套本地规则算法，无需 AI 服务或 API Key。气质与数量可以独立组合；当基准色锁定时，该颜色的饱和度或明度可以超出所选气质范围。整体效果仍应以自己的设计判断为准。

暖调将生成色相向米杏、赭橙、暖红方向收拢，冷调向青蓝、灰紫方向收拢。这会柔化所选色彩关系的色相间距；锁定的基准色保持准确色值，即使它本身属于另一种冷暖气质。

CMYK 为无 ICC 配置的屏幕近似换算；同一个 RGB 可对应不同 CMYK 黑版组合。印刷前请按目标纸张与印刷配置转换并打样。渐变预览包含插值色，导出的色卡只包含原始端点色。

## 开发与构建

零运行时依赖，原生 HTML / CSS / JavaScript。选色和导出都在本地执行，无数据上传。

```powershell
# 在本文件夹运行，生成/更新单文件发布版
powershell -ExecutionPolicy Bypass -File .\build.ps1

# 简单语法检查
node --check .\color-engine.js
node --check .\app.js
```

无需 npm install。修改源文件后重新生成单文件版。

配色预览的呈现形式参考了 [Khroma Generator](https://www.khroma.co/generator)；界面、图形、代码与推荐算法均在本项目中独立实现。
